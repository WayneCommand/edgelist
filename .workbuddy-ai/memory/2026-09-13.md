### `t` 要不要进依赖数组：两页故意做相反的选择

摸底时担心的「切语言导致 `load` 换身份 → 重拉列表」是真的，但**没有用 `useRef` 绕**（那样

- `StoragesPage` / `MetadataPage`：把 `t` 放进 `[notify, t]`。代价是切语言多读一次短列表。

两处都留了注释说明为什么做相反的选择——这是刻意的取舍，不是漏改。

### 浏览器验收：44 项，0 失败（`/tmp/verify_admin_i18n.cjs`）

覆盖三个页面在英/中两种语言下的标题、eyebrow、按钮、表头、行内动作、状态、开关、placeholder；
导航栏本身也随语言切换；切回英文后不残留中文；`localStorage` 的 `edgelist:locale` 在刷新后保持。

写这个脚本踩了两个坑，都是**脚本自己的**问题，记下来免得重犯：

1. **管理页的路由是 `/@manage/*`，不是 `/storages`。** 用错 URL 会落到 `FilesPage` 的
   `path="*"` 兜底，然后永远等不到表格。`ROUTES` 在 `src/react-app/routes.ts`：
   `/@login`、`/@manage/storages`、`/@manage/metadata`、`/@manage/backup-restore`。
2. **别用 `page.addInitScript` 钉 `localStorage` 的语言。** init script **每次导航都会跑**，
   所以每次 `page.goto` 都把语言重置回英文，切到中文后再跳页就白切了。正解是给
   browser context 一个 `locale: "en-US"`（`localeFrom(navigator.language)` 会回落到英文），
   之后让 `setLocale` 自己往 `localStorage` 写。
3. **读文案别用 `<main>`，用页面自己的 `<section>`。** 语言选择器在 header 里，永远带着
   字面量选项「中文」，`main` 范围的 CJK 扫描会在英文页面上误报。
4. **`placeholder` 不在 `innerText` 里**，是属性，得用 `getAttribute("placeholder")` 读。
5. 新建 S3 存储草稿有 4 个 `required` 字段（`endpoint`/`bucket`/`access_key_id`/
   `secret_access_key`），浏览器原生校验会**先**挡住 submit，`onSubmit` 根本不触发。
   要测重复挂载那条校验，得先把所有 `[required]` 填上。
