需要翻译的字符串分布（全部是页面/组件字面量，驱动注册表来的 `humanize(item.name)` 与
`item.help` **不动**——那是 worker 侧的键名，且「完整语言包」在明确排除范围内）：

  在英文界面里也会显示中文。

- `components/storage/StorageForm.tsx`：Edit storage / Add storage / Save storage。
- `components/storage/StorageFields.tsx`：Loading drivers… / General / Export JSON / Import JSON /
  Driver / `{name} settings` + 切驱动的确认框（含 `{{name}}` 插值）。
- `components/storage/DriverField.tsx`：Enabled/Disabled、`(upstream order)`。
- `components/storage/StorageJsonDialog.tsx`：标题两态、凭据警告、导入说明、Copy JSON /
  Import / Copied to the clipboard / 两条错误兜底。
- `pages/MetadataPage.tsx`、`pages/BackupPage.tsx`：尚未细读。

**关键设计约束（沿用 8.x 定下的规矩）**：`StoragesPage.load` 是 `useCallback` 且坐在
`useEffect(..., [load])` 的依赖数组里。若让 `load` 捕获 hook 的 `t`，切语言会让 `load`
换身份 → effect 重跑 → **重新拉一次列表**。所以：
- **渲染出来的文案**用 `useT()` 的 `t`（必须订阅，否则切语言不刷新）。
- **命令式一次性 toast 的兜底文案**（在 memo 过的回调里）用 `lib/locale.ts` 的模块级 `t`
  ——它不响应式，但 toast 是「发出即定稿」，正是它被设计出来的用途。
