### 关键结论（后续实现按此执行）

- 挂载解析 `resolveStorage` 有真实缺陷：按**字符串长度**而非层级深度排序；
  disabled 挂载会阻塞外层挂载（应跳过而非抛错）。改法：抽 `selectStorage()` 纯函数。
- 缺 `ObjMask`（OpenList `internal/model/obj.go:239-257`），虚拟挂载点应为
  `Locked|Virtual`，中间层 `ReadOnly|Virtual`；前端靠它禁用操作入口。
- **完全没有排序**：`order_by/order_direction/folder_order` 字段前端可改但后端从未读取。
  OpenList 顺序是 `sortFiles`（name 用自然序）→ `extractFolder`（总是执行）。
- 存储表单字段硬编码在 `App.tsx`；OpenList 做法是 `/api/admin/driver/list`
  返回 `Item{name,type,default,options,required,help}`，前端动态渲染。
- `webdav_policy` 当前值 `302/302/proxy` 与 OpenList 的
  `302_redirect/use_proxy_url/native_proxy` 不兼容，备份无法双向迁移。
- `folder_order`(before/after) 应改名对齐 OpenList 的 `extract_folder`(front/back)。
- Meta ACL 只有 CRUD，未接入 `fs/*`；`/api/me` 硬编码 is_admin。
- 前端 `App.tsx` 单文件承载全部页面，且文件页缺多选/框选/右键/网格视图/拖放/排序 UI，
  复制移动 API 后端已有但前端未接。

### 落地要点（后续阶段依赖）

- **归一化统一走 `SelectRule`**（`src/worker/storage/config.ts`）：
  `EXTRACT_FOLDER`(before/after→front/back) / `ORDER_BY`(含 created→name，
  `""` 保留=OpenList 的"不排序") / `WEBDAV_POLICY`(302→302_redirect, proxy→native_proxy)。
  缺字段返回 `undefined` 即不写入，保证"缺失"不被误填。
- **`src/worker/sort.ts`**（新增）：`compareNatural`（按数字分段，
  文本段用 code point 比较以免受 locale 影响）、`sortObjects`、
  `extractFolder`（稳定排序，只搬目录不破坏组内顺序）、
  `resolveSort(request, storage)`（请求参数 > storage > `DEFAULT_SORT`）、`applySort`。
- **`selectStorage(configs, path)`**（`config.ts`）：先过滤 `disabled` 再做最长前缀匹配，
  按 `mountDepth` 降序、长度次之、字典序兜底。旧实现是在选完后再判 disabled 直接抛错，
  导致 disabled 的内层挂载会阻塞外层挂载——已修。
  *注意：对"都能匹配"的候选集，深度与长度必然同序，深度排序主要是显式与确定性收益。*
- **虚拟目录 `mask`**：直接子挂载 = `OBJ_LOCKED|Virtual`；只为到达更深层挂载而存在的
  中间层 = `OBJ_READ_ONLY|Virtual`；同名去重时若后来者是直接挂载则升级为 `Locked|Virtual`
  （对齐 `internal/op/storage.go:378-443`）。
- **`FileObject` 新增** `mask`、`provider`（驱动名 `object`/`webdav`/`openlist`；
  openlist 适配器保留上游自带 provider）。`StorageConfig` 新增 `modified?`（admin 存盘时早已写入，
  只是类型未声明）——虚拟目录的 `modified` 取自它，不再固定 epoch。
- **踩到的真 bug**：S3 返回的 ETag 是 XML 转义的 `&quot;`，旧代码只 `replaceAll('"','')`，
  导致 `hashinfo.etag` 带引号。现改为先剥 `&quot;` 再校验 32 位 hex，
  多段上传的 `<md5>-<parts>` 一律不作为 MD5 上报。
